# Etichette di triage

Le skill parlano di cinque ruoli di triage canonici. Questa tabella li associa alle etichette usate nell'issue tracker di questo repo.

| Etichetta in mattpocock/skills | Etichetta nel nostro tracker | Significato                                  |
| ------------------------------ | ---------------------------- | -------------------------------------------- |
| `needs-triage`                 | `needs-triage`               | Il maintainer deve valutare la issue         |
| `needs-info`                   | `needs-info`                 | In attesa di informazioni da chi l'ha aperta |
| `ready-for-agent`              | `ready-for-agent`            | Specificata del tutto, pronta per un agente AFK |
| `ready-for-human`              | `ready-for-human`            | Richiede il lavoro di una persona            |
| `wontfix`                      | `wontfix`                    | Non verrà fatta                              |

Quando una skill nomina un ruolo (per esempio "applica l'etichetta di triage per agenti AFK"), usa l'etichetta corrispondente di questa tabella.
